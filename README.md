# Qaiser Bukhari — AI / Machine Learning Portfolio

A complete Next.js, TypeScript and Tailwind CSS portfolio for Syed Qaiser Abbas Bukhari. It includes a responsive homepage, six directly linkable project pages, accessible project filters, research, skills, teaching, education, contact links and the actual supplied CV.

**Status: ready to deploy. This package has not been deployed to your Vercel account.** No API keys, database, authentication or paid service is needed to run the website.

## 1. Start on your computer

Install a current Node.js LTS release (Node.js 22 or 24 recommended). The build was checked with Node.js 24. Extract the ZIP, open the `qaiser-portfolio` folder in VS Code, then choose **Terminal → New Terminal**.

Run these commands one at a time:

```bash
npm ci
npm run dev
```

Open **http://localhost:3000**. Leave the terminal running while you work. Press **Ctrl+C** to stop it. The package lock records the exact dependency versions used for the verified build.

## 2. Check the production build

```bash
npm run build
npm run typecheck
npm run check:export
```

The site uses Next.js static export. `out/` is the production website generated by the build. The validation script checks all six project pages, local links, images and other referenced assets, anchor targets, titles, descriptions and primary headings.

Because `output: 'export'` is enabled, `next start` is not used. To preview the production build, stop the development server and run `npm start`, then open **http://localhost:3000**. This uses the included dependency-free static server. Vercel will serve `out/` after building.

## 3. Edit your content

The central content file is **`src/data/portfolio.ts`**. It contains:

- Name, role, location, contact addresses and CV path.
- All six projects, repository links, categories, technology tags and detail-page copy.
- Research topic, supervisor, research metrics and evaluation methods.
- Technical skill groups, experience and education.

Keep quotes and brackets intact when editing. Save the file and the local preview updates. Layout and section headings are in `src/app/page.tsx`; project page structure is in `src/app/projects/[slug]/page.tsx`. Colours, spacing and breakpoints are in `src/app/globals.css`.

To add another project, add an object following the `Project` type and choose an existing category. Next.js will generate its page automatically on the next build. If you intentionally change the number of projects, update the expected project count in `scripts/check-export.mjs` and any homepage copy that says “six”.

## 4. Replace an image or CV

Original AI-generated concept illustrations are included locally as compressed WebP files in `public/artwork/`. They are labelled as illustrations, not real app screenshots. The artwork was created with the built-in image-generation tool; the prompts are recorded in `ARTWORK.md`.

- Replace an artwork file using the same name, or change its `image` path in the data file.
- Keep project covers around 1280 × 853 pixels, preferably WebP. Update the image's `imageAlt` to describe the replacement accurately.
- Hero artwork is `public/artwork/hero.webp`.
- The social sharing image is `public/artwork/social.jpg` (1200 × 630).
- Replace the CV at `public/documents/syed-qaiser-abbas-bukhari-cv.pdf` with your actual updated PDF.
- Public files are referenced without the `public` prefix: `/artwork/rag.webp`, for example.

The supplied PDF is included unchanged. Its download is a normal working file link. Contact uses `mailto:` and opens the visitor's configured email application; there is no pretend message form.

## 5. Deploy to your own Vercel account

### Option A — GitHub and Vercel (recommended)

1. Create a new repository in your own GitHub account, for example `qaiser-portfolio`.
2. Upload this folder's **contents** to that repository. Include `package.json`, `package-lock.json`, `next.config.ts`, `src`, `public` and `scripts`. Do not upload `node_modules`, `.next` or `out`.
3. Sign in at **https://vercel.com** using your own account.
4. Select **Add New → Project**, connect GitHub and import the repository.
5. Select **Next.js** as the framework. If the repository contains the portfolio in a subfolder, set **Root Directory** to that folder. Otherwise leave it at the repository root.
6. Use build command **`npm run build`**, install command **`npm ci`** and output directory **`out`**. No runtime secrets are needed.
7. Select **Deploy**. Wait for Vercel to report success; the URL shown by Vercel is your real live address.
8. For complete absolute social-sharing image URLs, canonical links and sitemap entries, open **Project → Settings → Environment Variables**, add `NEXT_PUBLIC_SITE_URL` with your actual production URL (for example, the exact `https://...vercel.app` address Vercel assigned), and redeploy. Do not add a trailing slash. Repeat this step if you later use a custom domain.

Future pushes to your connected production branch trigger a new deployment. Verify the current Vercel account plan and usage terms in your account; this project does not require a paid feature.

### Option B — Vercel CLI

From inside the portfolio folder:

```bash
npm install -g vercel
vercel login
vercel
```

Follow the prompts to create a project under **your own account**, then run `vercel --prod` when you want a production deployment. Select Next.js and `out` if Vercel asks about the framework or output directory. Add `NEXT_PUBLIC_SITE_URL` through your project settings once the production address exists, then redeploy.

## 7. Accessibility and implementation

- Semantic landmarks, one primary heading per page and a skip link.
- Visible keyboard focus and native filter buttons with `aria-pressed`.
- Live filter result announcements, clear selected states and a mobile menu with Escape support.
- Reduced-motion support, meaningful image descriptions and responsive layouts.
- Locally bundled imagery and icons; no third-party font requests.
- General interface icons use Lucide. Local SVG brand marks are used for GitHub and LinkedIn.
- Static pages with client-side interactivity only where needed.

## 8. Content provenance and limits

Profile, project and research copy comes from the verified information supplied with the request. The previously supplied actual resume is available as the CV download.

The five supplied repository URLs are retained exactly. Repository inspection was unavailable in this environment, so their availability and internal implementation were **not independently verified**. No dataset, class names, model architecture, speed benchmark, extra features or accuracy scores were added beyond the supplied facts. Confirm repository visibility in your GitHub account before sharing the site publicly.

The `0.778` research result is explicitly associated with within-person brain-state decoding in fMRI stress research. It is not the brain tumour classifier's accuracy. Research is not represented as published work. JobPilot remains labelled **In development**, has no invented repository link, and distinguishes intended capabilities from confirmed development details.
