# Original concept artwork

Seven original illustrations were created with the built-in image-generation tool for this portfolio and optimised locally as WebP. None is a screenshot, scientific scan, sample prediction or dataset example. The social sharing JPG combines the hero artwork with portfolio typography.

## Shared direction for project covers

Use case: stylized-concept. Asset type: original project cover artwork for a professional AI portfolio. Premium editorial 3D rendering, midnight navy #091322 background, mint #69E6BD and blue #69A7FF with restrained gold #E8C17A, clean studio lighting, generous space, landscape 3:2 composition, subject centred. No text, no watermarks, no fake screenshots. One consistent portfolio art collection.

## Hero — `public/artwork/hero.webp`

Square composition, central object with generous negative space. No text, letters, numbers, logos, watermark, diagrams or application interface. Conceptual artwork, not a scientific scan.
